# Credit Score Prediction & Credit Risk Assessment

A responsive static website for a student project. It works directly in a browser and can be hosted free with **GitHub Pages**.

## Features
- Financial details form (income, debt, loan amount, credit history, missed payments, employment status)
- Illustrative credit category and risk assessment
- Explanation of factors used
- Debt-to-income indicator
- Downloadable text summary
- Mobile-friendly layout

## Important limitation
This is a **front-end educational demonstration** with transparent, rule-based illustrative logic in `script.js`. It does **not** contain a trained machine-learning model and does not calculate an official credit score. Do not enter real personal or financial information or use the result for real lending decisions.

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in Chrome, Firefox, Edge, or another modern browser.

No installation or build step is required.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public repository**, for example `credit-score-prediction`.
2. Upload the files from this folder to the repository's **root**. Make sure `index.html`, `style.css`, and `script.js` are at the top level, not inside another nested folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait a minute or two and refresh the Pages section. GitHub will show the published website URL.

If you use GitHub mobile, open the repository in your browser and use **Add file → Upload files**. Upload the three website files and `README.md`.

## Files
- `index.html` — page structure
- `style.css` — visual design and responsive layout
- `script.js` — demo assessment logic and downloadable report
